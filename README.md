# Mark Asare Portfolio

Personal portfolio site for Mark Asare, focused on machine learning engineering, AI systems, MLOps, AWS, Azure, and full-stack product delivery.

Live site: https://markasare.com/

## Overview

This repository contains a Flask-based portfolio application that serves the public website, contact form endpoint, technical SEO surfaces such as `robots.txt` and `sitemap.xml`, and a lightweight analytics admin view.

The site is deployed serverlessly on AWS Lambda.

## Main Pages

- `/` - homepage
- `/about` - background and story
- `/experience` - work history, skills, and certifications
- `/projects` - selected shipped work
- `/research` - publications and IEEE research
- `/contact` - contact page and message form
- `/ml-ai-full-stack-engineer-aws-azure` - focused capability landing page
- `/admin` - public analytics dashboard

## Tech Stack

- Python
- Flask
- Flask-Mail
- boto3
- aws-wsgi
- HTML templates + static CSS/JS assets

## Local Development

Create and activate a virtual environment, install dependencies, then run the Flask app.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

The app runs locally at:

```text
http://127.0.0.1:5000
```

## Deployment

The repository includes a deployment script for AWS Lambda:

```bash
./deploy.sh
```

That script:

- installs Python dependencies into a build directory
- packages the Flask app, templates, and assets into a zip
- updates the Lambda function code
- waits for the Lambda update to complete
